# Calculator (MVP)

A simple, self-contained calculator web app. No build step, no dependencies — just open the file in a browser.

## Run it

Open `index.html` in any browser. That's it.

## Features

- Add, subtract, multiply, divide
- Chained operations (e.g. `2 + 3 × 4`)
- Percent (`%`), sign toggle (`±`), decimals
- Thousands separators and floating-point cleanup
- Divide-by-zero shows `Error`
- Full keyboard support:
  - Digits `0`–`9`, `.`
  - `+  -  *  /` for operators
  - `Enter` or `=` to evaluate
  - `Esc` to clear, `Backspace` to delete, `%` for percent

## Files

- `index.html` — markup
- `style.css` — styling (dark, rounded, iOS-style)
- `script.js` — calculator logic
